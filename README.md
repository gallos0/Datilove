# Datilove

Uma máquina de escrever para o seu Mac ou Windows.

- Página de download: https://gallos0.github.io/datilove/
- App: https://gallos0.github.io/datilove/app/

O app é instalável (PWA) pelo Chrome, Edge ou Safari e se atualiza sozinho a cada abertura com internet.
`src/` guarda a fonte do app e o script que gera o site.
